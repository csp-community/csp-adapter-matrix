## Pre-requisites

You need Python >=3.10 on your machine to install `csp-adapter-matrix`.

## Install with `pip`

```bash
pip install csp-adapter-matrix
```

## Install with `conda`

```bash
conda install csp-adapter-matrix --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `csp-adapter-matrix` from source](Build-from-Source).
